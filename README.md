# آریان پیشرو | ARIAN PISHRO

فروشگاه تخصصی سیستم‌های گیمینگ، لپ‌تاپ، کارت گرافیک و تجهیزات — با الهام از Razer و MAINGEAR

**لینک زنده:** https://avazpoors-stack.github.io/arian-pishro/

## ترکیب طراحی

- **از Razer:** مشکی مطلق `#000` + سبز نئونی `#00FF00`، هاله نور، تایپوگرافی جسورانه، هیروی تمام‌صفحه سینمایی
- **از MAINGEAR:** نوار اطلاع‌رسانی، کارت محصول با مشخصات فنی شفاف، تایل‌های دسته‌بندی تصویری، بخش PC Builder
- **از Stockland:** کارت کامل با بج موجودی + کد کالا + برند، ردیف‌های مشخصات روی کارت، صفحه محصول با باکس ویژگی‌ها + نوار ارسال + تب‌های مشخصات فنی
- **سطح دکمه گوگل:** سیستم توکن رنگ تست‌شده، حالت‌های Hover/Active/Focus/Loading/Done، ریپل متریال، Shine برق نور، کنتراست 15.3:1

## اصول UX اعمال‌شده

| # | اصل | پیاده‌سازی |
|---|-----|------------|
| 01 | Closure | ریل افقی با پیک 15% کارت بعدی |
| 02 | Figure-Ground | هاور روی گرید → بقیه کارت‌ها dim + blur سبد |
| 03 | Banner Blindness | بنر به راهنمای خرید محتوایی تبدیل شد |
| 04 | Parkinson | فرم تسویه با localStorage از پیش پر |
| 05 | Connectedness | استپر متصل 1→2→3→4 + خط تسویه |
| 06 | Choice Overload | 6 محصول اول + نمایش بیشتر + 3 پریست |

## ساختار

```
/index.html
/assets/style.css — دیزاین سیستم کامل
/assets/app.js — فروشگاه، فیلتر، سبد، بیلدر
/assets/images/ — تصاویر سینمایی اختصاصی
```

## اجرا

فقط فایل `index.html` را باز کنید — بدون نیاز به بک‌اند.

## ویژگی‌های ویترین

- جستجوی زنده (⌘K)، فیلتر دسته‌بندی، مرتب‌سازی
- سبد کشویی با جمع کل و فرم تسویه
- مودال محصول کامل به سبک Stockland
- سیستم‌ساز تعاملی با محاسبه قیمت/وات لحظه‌ای
